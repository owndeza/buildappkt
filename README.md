# PersistentIsland

PersistentIsland — экспериментальное нативное приложение для запуска минимальной Live Activity через официальные API ActivityKit и WidgetKit. Live Activity может отображаться в Dynamic Island на поддерживаемых системой устройствах. Приложение не модифицирует SpringBoard, MobileGestalt и системные файлы.

> PersistentIsland uses Live Activities. iOS controls when activities appear and how long they remain active. Permanent visibility cannot be guaranteed.

## Возможности

- запуск, остановка и ручной перезапуск одной Live Activity;
- восстановление фактического состояния после перезапуска приложения;
- защита от создания дубликатов;
- визуально пустые минимальный, компактный и расширенный макеты Dynamic Island — без таймера, точки, текста и анимации;
- светлая и тёмная тема интерфейса приложения;
- локальная диагностика без сбора и отправки данных;
- unsigned device-сборка и упаковка IPA в GitHub Actions.

## Поддерживаемые устройства

Проект имеет deployment target iOS 16.2 — это минимальная версия для используемого современного API Live Activities. Официальное отображение в Dynamic Island доступно только на совместимых моделях iPhone. Целевой iPhone 13 из условий задачи использует неофициальную модификацию MobileGestalt/GestaltEdit; работоспособность Dynamic Island на такой конфигурации Apple не гарантирует.

Проект не содержит кода для применения или изменения этой модификации. Будущая iOS 27 Beta должна запускать приложение как обратно совместимое, однако фактическая совместимость проверяется только на устройстве и с доступным Apple SDK — проект не использует несуществующие «iOS 27 API».

## Архитектура

- `PersistentIsland` — SwiftUI-приложение и `ActivityManager`;
- `PersistentIslandWidget` — WidgetKit extension с `ActivityConfiguration` и `DynamicIsland`;
- `Shared` — общий `IslandAttributes` и конфигурация, компилируемые в оба target;
- `Tests` — unit-тесты редьюсера состояния и блокировки повторного запуска;
- `project.yml` — воспроизводимое описание проекта для XcodeGen;
- `Scripts` — device build и упаковка `Payload/PersistentIsland.app`;
- `.github/workflows/buildapp.yml` — CI-сборка unsigned IPA.

Bundle identifiers:

- приложение: `com.owndeza.persistentisland`;
- extension: `com.owndeza.persistentisland.widget`.

## Сборка через GitHub Actions

1. Откройте репозиторий на GitHub.
2. Перейдите в **Actions**.
3. Выберите **Build PersistentIsland**.
4. Нажмите **Run workflow** и подтвердите запуск ветки `main`.
5. Дождитесь зелёного результата job `build`.
6. Внизу страницы запуска скачайте artifact `PersistentIsland-unsigned`.
7. Распакуйте artifact: внутри находится `PersistentIsland-unsigned.ipa`.

Workflow использует установленный на runner Xcode, сначала печатает его версию и доступные SDK, генерирует `.xcodeproj`, собирает настоящий `iphoneos` arm64 bundle без подписи, проверяет вложенный `.appex` и структуру IPA. Успешная unsigned-сборка ещё не означает, что IPA можно установить без последующей корректной подписи.

## Локальная сборка на macOS

Требуются Xcode и XcodeGen:

```bash
brew install xcodegen
Scripts/build.sh
Scripts/package-ipa.sh
```

На Windows Xcode и Apple iOS SDK недоступны, поэтому используйте GitHub Actions или Mac.

## Подпись и установка на Windows

Для установки unsigned IPA требуется легитимная подпись вашим Apple ID/сертификатом. Например, в Sideloadly:

1. скачайте и установите Sideloadly и необходимые компоненты Apple;
2. подключите iPhone кабелем и подтвердите доверие компьютеру;
3. перетащите `PersistentIsland-unsigned.ipa` в Sideloadly;
4. выберите устройство, укажите свой Apple ID и запустите подпись/установку;
5. при необходимости подтвердите профиль разработчика на iPhone в настройках управления устройством;
6. на iOS 16+ включите Developer Mode, если система этого потребует.

Приложение и WidgetKit extension имеют разные bundle identifier и должны быть подписаны совместимыми provisioning profiles. Инструмент подписи обязан сохранить вложенный extension, его identifier и конфигурацию Live Activities. Не все sideloading-инструменты корректно переподписывают расширения; бесплатная учётная запись также имеет ограничения по сроку и возможностям.

Не добавляйте в репозиторий сертификаты, пароли, Apple ID, provisioning profiles или токены.

## Использование

1. Запустите PersistentIsland.
2. Убедитесь, что ActivityKit отмечен как доступный.
3. Нажмите **Start Island**.
4. Вернитесь на домашний экран.
5. Проверьте системный Dynamic Island и экран блокировки.
6. Проверьте совместное поведение с музыкой и таймерами — приоритет выбирает iOS.
7. Нажмите **Stop Island**, когда активность больше не нужна.

Preview внутри приложения — только локальный макет, не системный оверлей.

ActivityKit не предоставляет приложению список Live Activities других приложений и не сообщает, какая активность сейчас видима в Dynamic Island. Поэтому PersistentIsland остаётся активной, а временное скрытие и повторное отображение при появлении музыки, таймера или другой системной активности полностью контролирует iOS. Автоматически завершить нашу Activity при появлении чужой и заново создать её после исчезновения без фонового выполнения или частных API невозможно.

## Диагностика

Экран настроек показывает версию iOS, публичное название класса устройства, статус разрешения, число активностей, activity ID, состояние, время запуска и последнюю ошибку. **Копировать диагностику** помещает эти данные в буфер обмена. Приватные аппаратные идентификаторы не читаются.

## Устранение неполадок

### ActivityKit недоступен

Проверьте системные настройки приложения и разрешение Live Activities. Убедитесь, что iOS не отключила Live Activities глобально и устройство работает на iOS 16.2 или новее.

### Активность запущена, но Dynamic Island не отображается

Проверьте экран блокировки: Live Activity может существовать, даже если iOS не показывает её в острове. Система сама управляет приоритетом, а модифицированный iPhone 13 официально не поддерживается.

### Widget extension не загрузился

Убедитесь, что после подписи в `PersistentIsland.app/PlugIns` сохранён `PersistentIslandWidget.appex`, а приложение и extension подписаны совместимыми профилями.

### Активность исчезает или истекает

Это нормальное системное поведение. iOS определяет срок жизни и может завершить или скрыть Live Activity. Откройте приложение и используйте **Restart Island**; фонового цикла для обхода ограничений нет.

### Ошибка подписи IPA

Проверьте уникальность обоих bundle identifiers, срок сертификата, provisioning profiles и поддержку расширений выбранным инструментом. Удалите старую установленную сборку, если её подпись конфликтует.

### Ошибка установки

Проверьте доверие компьютеру, Developer Mode, свободные слоты бесплатной подписи, срок профиля и совместимость версии iOS. Смотрите точный текст ошибки Sideloadly.

### Проблемы совместимости устройства

Dynamic Island на базовом iPhone 13 с MobileGestalt-модификацией остаётся неофициальной конфигурацией. Даже корректная ActivityKit activity не гарантирует системное отображение.

## Ограничения

- нет jailbreak-компонентов и SpringBoard injection;
- нет изменения MobileGestalt или аппаратных идентификаторов;
- нет постоянного системного оверлея;
- нет гарантии постоянной видимости Dynamic Island;
- нет неподдерживаемого фонового выполнения, silent audio или фиктивной навигации;
- iOS полностью контролирует срок жизни и приоритет Live Activities;
- unit-тесты и CI-сборка не заменяют проверку на физическом устройстве.
